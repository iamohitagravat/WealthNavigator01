# Indian Market Pro Trading Assistant

A ChatGPT-oriented trading assistant framework for Indian markets (NSE/BSE), covering NIFTY, BANK NIFTY, equities, futures and options.

## Scope
- Scalping, intraday, swing and positional analysis
- Technical analysis and price action
- Support/resistance, entries, exits and trade plans
- Risk management and position sizing
- Indian-market context: NSE/BSE sessions, F&O expiries, lot sizes, FII/DII flows and corporate events
- Paper-trading/backtesting architecture

## Safety
This project is analysis-first. Live order execution is disabled by default. Any future broker integration should require explicit authorization and appropriate safeguards.
